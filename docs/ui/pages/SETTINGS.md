## 常规

- 开机启动 [默认开]
- “关闭窗口后继续后台运行”仅说明，不是 Toggle
- 应用主题：跟随系统 / 浅色 / 深色

Startup 启动 Agent，不自动打开 WinUI。

## 更新

- 当前版本
- 在 Microsoft Store 中查看

GitHub：

- 自动检查软件更新 [开]
- 当前版本
- 检查更新

- 自动检查主题更新 [开]

## Cache

显示占用空间。

`清理缓存` 只删可再生成：

- rendered
- previews
- downloads
- temp extraction

不删已安装 Theme / Settings / Secrets。

不能让当前桌面黑掉。

## Logs

- 保留 7 天（固定）
- 打开日志文件夹
- 无 Telemetry
- 无第三方 Crash Reporter

## AI 服务

Secret 不进 JSON / logs。
