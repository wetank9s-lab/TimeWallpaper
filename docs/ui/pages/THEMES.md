## Theme Detail

完整页面，不用弹窗。

大图 + 八阶段时间轴。

时间轴：

- 点击八个节点
- 不连续拖动
- 不暗示渐变帧

可显示用户当前位置的真实 Solar 时间。

## 下载

下载完成后不自动应用。

当前主题更新成功后：

- 替换 Theme
- 清旧 Render Cache
- 重新渲染当前阶段
- 立即刷新桌面

无需再次点击应用。
